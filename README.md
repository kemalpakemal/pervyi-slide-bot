# Первый слайд

Telegram-бот студии дизайна карточек товаров для Wildberries, Ozon и Avito.

## Стартовый прайс

- Обложка — 790 ₽.
- Инфографика — 590 ₽ за слайд.
- 2 слайда — 1 290 ₽.
- 3 слайда — 1 890 ₽.
- 5 слайдов — 2 890 ₽.
- 7 слайдов — 3 790 ₽.
- 10 слайдов — 4 990 ₽.
- Дополнительный слайд — 490 ₽.

Цены хранятся в `config/price.yaml`.

## Генерация изображений через OctavApi

Генератор использует endpoint `POST https://octavapi.shop/v1/images/generations`, модель `image_gen`, поля запроса `model`, `prompt` и `size`. Это соответствует инструкции подключения OctavApi. Ответ принимается в распространённых форматах Images API: `data[0].b64_json`, `data[0].url`, `output[0]` или аналогичные поля верхнего уровня. Если фактическая схема отличается, бот покажет безопасную диагностику без вывода API-ключа.

Для каждого слайда создаётся отдельный фон. Исходный товар не отправляется на перерисовку: бот удаляет фон с фото товара и совмещает исходный объект со сценой через Pillow.

Итоговый формат — 1200×1600. Клиенту отправляется только демо-копия:
- максимальная сторона 700 px;
- повторяющийся диагональный водяной знак «ПЕРВЫЙ СЛАЙД • ДЕМО»;
- крупная надпись «ДЕМО».

Чистые оригиналы остаются в закрытом Railway Volume.

### Настройка OctavApi

Добавь в Railway → `pervyi-slide-bot` → Variables:
- `OCTAVAPI_API_KEY` — секретный API-ключ из кабинета OctavApi;
- `IMAGE_PROVIDER=octavapi`;
- `OCTAVAPI_BASE_URL=https://octavapi.shop/v1`;
- `OCTAVAPI_IMAGE_MODEL=image_gen`;
- `OCTAVAPI_IMAGE_SIZE=1024x1024`.

Не вставляй ключ в GitHub, код, Telegram или этот чат. Сначала проверь в OctavApi, что в списке моделей доступна генерация изображений и на балансе есть средства. Каждый запрос может расходовать баланс. Для первой проверки запускай один слайд.

## Клиентский режим

- `/start` — главное меню.
- Пошаговый бриф: площадка, товар, преимущества, обязательные тексты, стиль, цвета, количество слайдов и срок.
- Приём фото и документов-изображений JPG/PNG/WEBP.
- Подтверждение брифа создаёт заявку в PostgreSQL и отправляет её администратору.
- «Примеры работ» — файлы из `content/examples/`.
- «Цены» — значения из `config/price.yaml`.
- «Связаться с автором» — передача сообщения администратору.

## Команды администратора

- `/orders` — последние 20 заказов и статусы.
- `/review` — открыть последнюю заявку, ожидающую проверки; `/review <ID>` — открыть конкретную.
- В карточке заявки: принять, запросить уточнение, отклонить.
- После принятия появляется кнопка «Сгенерировать демо» — ID вводить не нужно.
- `/generate` — сгенерировать демо для последней принятой заявки; `/generate <ID>` — для конкретной.
- Повторный клик не запускает параллельную генерацию: статус заявки проверяется перед запуском.
- `/health` — проверка БД.
- `/order` — создать черновик заказа из пересланных сообщений.
- `/paid` и `/remind` — заглушки; подтверждение оплаты и выдача чистых оригиналов пока не включены.

## Хранение

- PostgreSQL: клиенты, заявки, FSM, статусы и Telegram file_id.
- Railway Volume: исходные и сгенерированные изображения.
- `/stop` отключает инициативные сообщения.
- `/forget` удаляет профиль и связанные строки БД. Файлы на диске пока не удаляются автоматически.

## Railway

Переменные описаны в `.env.example`. Docker build выполняет `compileall` и останавливает деплой при синтаксических ошибках Python.
