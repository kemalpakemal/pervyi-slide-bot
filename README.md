# Первый слайд

Telegram-бот студии дизайна карточек товаров для Wildberries, Ozon и Avito.

## Стартовый прайс

- Обложка — 790 ₽.
- Инфографика — 590 ₽ за слайд.
- 2 слайда — 1 290 ₽.
- 3 слайда — 1 890 ₽.
- 5 слайдов — 2 890 ₽.
- 7 слайдов — 3 790 ₽.
- 10 слайдов — 4 990 ₽.
- Дополнительный слайд — 490 ₽.

Цены хранятся в `config/price.yaml`.

## Автономная генерация изображений

После подтверждения брифа бот автоматически запускает OpenAI Images API, накладывает водяной знак и отправляет демо администратору и клиенту, не ожидая нажатия кнопок администратора. Если клиент запросит правки, следующее текстовое сообщение добавляется в бриф и запускается новая генерация. Администратор получает результат для контроля, но его проверка не блокирует отправку клиенту. Генератор может ошибаться в тексте и деталях товара: проверяйте результаты.

Для работы задайте `OPENAI_API_KEY` в Railway Variables и включите оплату API у OpenAI. Подписка ChatGPT не является API-доступом; каждый слайд и повторная генерация расходуют средства. `OPENAI_IMAGE_MODEL` по умолчанию — `gpt-image-1`. Фотография первого вложения передаётся в Images API; остальные изображения не используются как визуальные референсы. Без ключа либо при ошибке API результат не создаётся: администратор получает уведомление и может повторить через `/generate <ID>`. Частичный комплект клиенту не отправляется. Доставка через Telegram также зависит от доступности бота и клиента.

`PAYMENT_LINK` и `PAYMENT_REQUISITES` необязательны. Кнопка «Я оплатил» сама по себе не подтверждает оплату: администратор должен проверить поступление и выполнить `/paid <ID>`, после чего бот отправляет оригиналы. Автоматического платёжного провайдера здесь нет. При перезапуске незавершённая генерация запускается повторно, что может повлечь дополнительные расходы; сохраните базу и `STORAGE_PATH` на постоянном томе. При сбое доставки повтор может привести к дублированию отдельных сообщений.

## Клиентский режим

- `/start` — главное меню.
- Пошаговый бриф: площадка, товар, преимущества, обязательные тексты, стиль, цвета, количество слайдов и срок.
- Приём фото и документов-изображений JPG/PNG/WEBP.
- Подтверждение брифа создаёт заявку и запускает генерацию; администратор получает бриф и демо.
- «Примеры работ» — файлы из `content/examples/`.
- «Цены» — значения из `config/price.yaml`.
- «Связаться с автором» — передача сообщения администратору.

## Команды администратора

- `/orders` — последние 20 заказов и статусы.
- `/review` — открыть последнюю заявку, ожидающую проверки; `/review <ID>` — открыть конкретную.
- В карточке заявки: принять, запросить уточнение, отклонить.
- `/generate <ID>` — повторить неудачную генерацию.
- После загрузки можно добавить следующие слайды или отправить все демо клиенту.
- `/demo <ID>` — резервная загрузка изображения ответом на сообщение с картинкой.
- `/health` — проверка БД.
- `/order` — создать черновик заказа из пересланных сообщений.
- `/paid <ID>` — вручную подтвердить проверенную оплату и отправить оригиналы. `/remind` — заглушка.

## Хранение

- PostgreSQL: клиенты, заявки, FSM, статусы и Telegram file_id.
- Railway Volume: исходные и сгенерированные изображения.
- `/stop` отключает инициативные сообщения.
- `/forget` удаляет профиль и связанные строки БД. Файлы на диске пока не удаляются автоматически.

## Railway

Переменные описаны в `.env.example`. Docker build выполняет `compileall` и останавливает деплой при синтаксических ошибках Python.
