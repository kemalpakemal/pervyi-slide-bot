# Первый слайд

Telegram-бот студии дизайна карточек товаров для Wildberries, Ozon и Avito.

## Стартовый прайс

- Обложка — 790 ₽.
- Инфографика — 590 ₽ за слайд.
- 2 слайда — 1 290 ₽.
- 3 слайда — 1 890 ₽.
- 5 слайдов — 2 890 ₽.
- 7 слайдов — 3 790 ₽.
- 10 слайдов — 4 990 ₽.
- Дополнительный слайд — 490 ₽.

Цены хранятся в `config/price.yaml`.

## Изображения через ChatGPT

Генерация выполняется во встроенном ChatGPT Images в отдельном диалоге. Railway-бот не может напрямую запускать встроенный генератор из чата и не использует внешний Images API.

Рабочий процесс:
1. Администратор передаёт ChatGPT бриф и исходное фото товара.
2. ChatGPT создаёт готовый слайд.
3. Администратор делится изображением из мобильного приложения ChatGPT в Telegram → `@pervy_slide_bot`. Если прямое меню «Поделиться» недоступно, изображение можно сохранить и отправить боту.
4. Администратор отвечает на сообщение с изображением командой `/demo <ID заявки>`.
5. Бот сохраняет исходное изображение на Railway Volume, создаёт демо-копию до 700 px с повторяющимся диагональным водяным знаком «ПЕРВЫЙ СЛАЙД • ДЕМО» и крупной надписью «ДЕМО».
6. Бот показывает демо администратору. Клиент получает его только после нажатия «Отправить демо клиенту».

Встроенная генерация ChatGPT не вызывается из Railway автоматически. Между ChatGPT и Telegram остаётся одно действие администратора — передать готовое изображение через «Поделиться».

## Клиентский режим

- `/start` — главное меню.
- Пошаговый бриф: площадка, товар, преимущества, обязательные тексты, стиль, цвета, количество слайдов и срок.
- Приём фото и документов-изображений JPG/PNG/WEBP.
- Подтверждение брифа создаёт заявку в PostgreSQL и отправляет её администратору.
- «Примеры работ» — файлы из `content/examples/`.
- «Цены» — значения из `config/price.yaml`.
- «Связаться с автором» — передача сообщения администратору.

## Ручная передача изображений из ChatGPT

Встроенный генератор ChatGPT не вызывается Railway-сервисом напрямую. Для работы без внешнего API используется ручная передача результата:
1. Администратор передаёт фото товара и бриф в ChatGPT, получает готовый макет.
2. В мобильном ChatGPT открывает изображение → «Поделиться» → Telegram → `@pervy_slide_bot`. Если Telegram не появился в меню «Поделиться», изображение можно сохранить и отправить боту как фото.
3. В чате с ботом отвечает на отправленное изображение командой `/demo <ID заявки>`.
4. Бот сохраняет исходный файл в Railway Volume, делает уменьшенную демо-копию с повторяющимся водяным знаком и отправляет её администратору.
5. Администратор проверяет демо и нажимает «Отправить демо клиенту». До этого клиент ничего не получает.

Пример: ответ на изображение командой `/demo 2c19e81f`. Заявка должна быть предварительно принята. Можно отправлять несколько слайдов по одному, каждый с ответом `/demo <ID>`.

## Команды администратора

- `/orders` — последние 20 заказов и статусы.
- `/review` — открыть последнюю заявку, ожидающую проверки; `/review <ID>` — открыть конкретную.
- В карточке заявки: принять, запросить уточнение, отклонить.
- После принятия появляется кнопка «Сгенерировать демо» — ID вводить не нужно.
- `/generate` — сгенерировать демо для последней принятой заявки; `/generate <ID>` — для конкретной.
- Повторный клик не запускает параллельную генерацию: статус заявки проверяется перед запуском.
- `/health` — проверка БД.
- `/order` — создать черновик заказа из пересланных сообщений.
- `/paid` и `/remind` — заглушки; подтверждение оплаты и выдача чистых оригиналов пока не включены.

## Хранение

- PostgreSQL: клиенты, заявки, FSM, статусы и Telegram file_id.
- Railway Volume: исходные и сгенерированные изображения.
- `/stop` отключает инициативные сообщения.
- `/forget` удаляет профиль и связанные строки БД. Файлы на диске пока не удаляются автоматически.

## Railway

Переменные описаны в `.env.example`. Docker build выполняет `compileall` и останавливает деплой при синтаксических ошибках Python.
