# Первый слайд

Telegram-бот студии дизайна карточек товаров для Wildberries, Ozon и Avito.

## Прайс на запуск

- Обложка — 790 ₽.
- Инфографика — 590 ₽ за слайд.
- 2 слайда — 1 290 ₽.
- 3 слайда — 1 890 ₽.
- 5 слайдов — 2 890 ₽.
- 7 слайдов — 3 790 ₽.
- 10 слайдов — 4 990 ₽.
- Дополнительный слайд — 490 ₽.

Прайс хранится в `config/price.yaml`; кнопка «Цены» читает значения из этого файла.

## Генерация демо

Генератор использует Yandex AI Studio / Alice AI ART. Для каждого слайда он создаёт отдельный фон, удаляет фон с исходного фото товара и совмещает их средствами Pillow. Товар не перерисовывается нейросетью. Размер финального слайда — 1200×1600.

Для демо создаётся уменьшенная копия (максимальная сторона 700 px) с повторяющимся диагональным водяным знаком «ПЕРВЫЙ СЛАЙД • ДЕМО» и крупной надписью «ДЕМО». Оригиналы остаются в закрытом Railway Volume.

### Подключение Yandex AI Studio

Нужны активный платёжный аккаунт Yandex Cloud и два значения:
- `YANDEX_API_KEY` — API-ключ AI Studio с доступом к генерации изображений.
- `YANDEX_FOLDER_ID` — ID каталога Yandex Cloud.

Создай их в интерфейсе [Yandex AI Studio](https://aistudio.yandex.ru/): войди в аккаунт, привяжи активный платёжный аккаунт, нажми «Создать API-ключ» и сохрани секрет ключа. Затем добавь `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` в Railway → `pervyi-slide-bot` → Variables. Не отправляй секрет в Telegram или этот чат.

Официальный тариф Yandex AI Studio для генерации изображений — 2,23 ₽ за запрос с НДС. Повторный запрос считается отдельной генерацией. Коммерческое использование разрешено при соблюдении законодательства.

### Команды администратора генерации

- `/generate <ID>` — сгенерировать слайды из принятой заявки.
- Кнопка «Отправить демо клиенту» отправляет только водяные превью.
- Кнопка «Перегенерировать» возвращает заявку в статус «Принята»; после этого запусти `/generate <ID>` ещё раз.

Финальные изображения хранятся на Railway Volume. Автоматическая выдача чистых файлов после подтверждения оплаты будет добавлена отдельным этапом; команда `/paid` пока не выдаёт оригиналы.

## Остальные возможности MVP

### Клиентский режим
- `/start` — главное меню.
- Пошаговый бриф: площадка, товар, преимущества, обязательные тексты, стиль, цвета, количество слайдов и срок.
- Приём фото, документов-изображений JPG/PNG/WEBP и ссылок/описаний референсов.
- Подтверждение брифа создаёт заявку в PostgreSQL и уведомляет администратора.
- «Примеры работ» — показывает файлы из `content/examples/`.
- «Цены» — читает только `config/price.yaml`.
- «Связаться с автором» — передаёт сообщение администратору.

### Режим ассистента
1. Администратор пересылает боту сообщения клиента подряд.
2. Отвечает командой `/order` на одно из пересланных сообщений.
3. Бот собирает материалы этого отправителя за последние 30 минут и создаёт черновик заказа.
4. Бот не пишет клиенту автоматически. Если Telegram скрывает ID отправителя, заказ не создаётся автоматически.

### Команды администратора
- `/orders` — последние 20 заказов и их статусы.
- `/review <ID>` — повторно открыть заявку, ожидающую проверки.
- Кнопки в карточке заявки: принять, запросить уточнение, отклонить.
- `/health` — проверка подключения к БД.
- `/order` — создать заказ из пакета пересланных сообщений.
- `/paid` и `/remind` — пока заглушки.

## Хранение и ограничения

- Брифы, заказы, FSM-состояния и Telegram file_id хранятся в PostgreSQL.
- FSM переживает перезапуск приложения.
- Исходное фото товара и созданные изображения сохраняются в `STORAGE_PATH`.
- `/stop` отключает инициативные сообщения (автоматических рассылок на этом этапе нет).
- `/forget` удаляет профиль и связанные записи из БД. Файлы на диске пока не удаляются автоматически — это отдельная задача для следующего этапа.

## Railway

Обязательные переменные:
- `BOT_TOKEN`
- `ADMIN_ID`
- `DATABASE_URL`
- `STORAGE_PATH=/data`
- `IMAGE_PROVIDER=yandex_art`
- `YANDEX_API_KEY`
- `YANDEX_FOLDER_ID`

Все параметры также перечислены в `.env.example`.
